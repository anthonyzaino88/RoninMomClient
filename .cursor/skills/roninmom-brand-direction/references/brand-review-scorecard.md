# Brand Review Scorecard

Score each category from 1–5 and cite visible evidence. Revise when any score is below 4.

| Category | Approval question |
| --- | --- |
| Brand distinctiveness | Would this still feel recognizably Ronin Mom without the logo? |
| Reader clarity | Can the intended reader understand the page's promise and next step quickly? |
| Editorial credibility | Does the page feel authored, specific, honest, and trustworthy? |
| Visual cohesion | Do type, color, spacing, imagery, and components form one restrained system? |
| Practical usefulness | Does the experience help the reader learn, decide, or act? |

Report the score, evidence, strongest element, weakest element, and required revisions.
