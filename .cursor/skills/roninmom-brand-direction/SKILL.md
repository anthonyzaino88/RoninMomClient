# Ronin Mom Brand Direction

Before a material brand change, read all of these direct references:

- [Brand foundation](references/brand-foundation.md)
- [Visual language](references/visual-language.md)
- [Voice and copy](references/voice-and-copy.md)
- [Competitive separation](references/competitive-separation.md)
- [Brand review scorecard](references/brand-review-scorecard.md)

## Workflow

1. Inspect the current route, shared components, tokens, fonts, imagery, and neighboring content.
2. State the page's reader, job, primary action, and connection to one or more content pillars.
3. Preserve working behavior, URLs, accessibility, analytics, and SEO unless the task changes them.
4. Apply the smallest coherent set of brand changes. Reuse sound primitives instead of creating a parallel design system.
5. Review mobile, tablet, and desktop output with realistic content.
6. Score the result with the brand scorecard. Revise any category below 4.

Do not invent family claims or private details to make the brand feel personal.
