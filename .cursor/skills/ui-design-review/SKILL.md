# UI Design Review

1. Identify the page purpose, reader, primary action, and first-viewport promise.
2. Review hierarchy, scanning, typography, line length, spacing rhythm, and grid alignment.
3. Check component consistency without forcing all content into identical cards.
4. Verify semantic controls, labels, keyboard use, focus visibility, contrast, and touch targets.
5. Check empty, loading, and error states when relevant.
6. Test mobile, tablet, and desktop behavior with long titles, missing images, narrow widths, and multiline navigation.
7. Apply the `roninmom-brand-direction` scorecard to public-facing work.

Report actionable findings in severity order. Never approve a page based only on attractive desktop styling.
