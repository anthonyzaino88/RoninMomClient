# Article Shapes

Select one primary shape. Combine shapes only when it improves the reader's path.

| Reader need | Recommended shape | Core sequence |
| --- | --- | --- |
| Complete a task | How-to guide | Outcome → prerequisites → ordered steps → troubleshooting → next step |
| Make a choice | Decision guide | Decision → criteria → options and tradeoffs → recommendation by situation |
| Learn from experience | Experience-led guide | Confirmed moment → lesson → practical framework → limits → reader application |
| Solve a recurring problem | Problem/solution | Symptoms of the problem → likely causes → solutions by effort → prevention |
| Build a routine | Family system | Goal → constraints → simple system → real-life adaptations → reset plan |
| Explore a topic | Field guide | Orientation → key concepts → practical entry points → mistakes → resources |
| Use seasonal timing | Seasonal guide | Why now → preparation → actions by stage → storage or follow-through |

## Outline test

Before drafting, confirm:

- The headline promises the same outcome the article delivers.
- Each section answers a distinct reader question.
- The most useful information is not delayed to manufacture suspense.
- Personal context has an identified purpose.
- Claims needing evidence are marked in the outline.
- The article includes constraints, alternatives, or failure cases where relevant.
- The ending gives a useful next action rather than summarizing every heading.

## Useful depth

Depth comes from specificity, not length. Add:

- Quantities, time ranges, materials, or conditions when verified
- A worked example or realistic scenario
- A comparison that reveals tradeoffs
- Common mistakes and recovery steps
- What changed the author's judgment, only when confirmed
- A short source note for claims a careful reader may want to verify

Remove background history, generic definitions, and broad benefits unless they help the reader decide or act.
