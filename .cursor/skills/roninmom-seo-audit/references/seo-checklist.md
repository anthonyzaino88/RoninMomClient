# SEO Checklist

Audit the rendered page for:

- Clear search intent and one primary page purpose
- Unique, useful title and description
- Consistent canonical URL and metadata base
- Correct indexability, robots directives, and sitemap membership
- Sitemap routes generated from real routes and content
- One logical H1 and semantic heading order
- Crawlable internal links and useful breadcrumbs
- Accurate `Article` or `BlogPosting`, `WebSite`, `Organization` or `Person`, and `BreadcrumbList` data only when visible content supports it
- No site-wide FAQ schema without matching visible FAQs
- Truthful author, published, and modified dates
- Open Graph and Twitter previews with meaningful images
- Image dimensions, loading behavior, and alt text
- Core Web Vitals risks and unnecessary client JavaScript
- Duplicate, thin, and low-value archive risks
- Trust signals, disclosures, and sources where relevant

Verify representative output rather than assuming framework helpers produce correct HTML.
