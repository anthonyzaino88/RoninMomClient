# Images Needed for Ronin Mom Website

## 📍 Location: `public/assets/img/`

Add these images to this folder:

## Required Images

### 1. **banner.png** (MOST IMPORTANT)
- **Size**: 1200×630 pixels (recommended)
- **Used for**: 
  - Homepage hero image
  - Blog post featured images (temporary)
  - Social media sharing preview
- **Where to get**: 
  - Use your actual logo/brand image
  - OR get from [Unsplash](https://unsplash.com/s/photos/japanese-mother)
  - OR create custom branded image

### 2. **facebook.svg**
- Social media icon for footer
- Download from: [Simple Icons](https://simpleicons.org/?q=facebook)
- OR use any Facebook icon SVG

### 3. **instagram.svg**
- Social media icon for footer
- Download from: [Simple Icons](https://simpleicons.org/?q=instagram)
- OR use any Instagram icon SVG

### 4. **pinterest.webp** (or .png/.svg)
- Social media icon for footer
- Download from: [Simple Icons](https://simpleicons.org/?q=pinterest)
- Can be .webp, .png, or .svg format

## Optional But Recommended

### Unique Blog Post Images
Create/find images for each blog post:
- **self-sufficient-living.jpg** - Garden/homestead image
- **holistic-wellness.jpg** - Wellness/meditation image
- **organic-cotton-dish-cloths.jpg** - Kitchen/sustainability image

Then update the `image:` field in each `.mdx` file.

## Quick Solutions

### Option 1: Use Placeholders (Fastest)
- Download one nice image and name it `banner.png`
- Use it for all posts temporarily
- Replace later with specific images

### Option 2: Free Stock Photos
Visit these sites for free, high-quality images:
- [Unsplash](https://unsplash.com/)
- [Pexels](https://pexels.com/)
- [Pixabay](https://pixabay.com/)

Search terms:
- "japanese mother baby"
- "sustainable living"
- "wellness meditation"
- "organic kitchen"
- "homestead garden"

### Option 3: Create Your Own
- Use Canva (free account)
- Create branded images with your logo
- Add text overlays with post titles
- Export as PNG (1200×630px)

## Image Optimization

Before adding images, optimize them:
- Use [TinyPNG](https://tinypng.com/) to compress
- OR [Squoosh](https://squoosh.app/) for WebP conversion
- Target: Under 200KB per image

## After Adding Images

1. Save images to this folder: `public/assets/img/`
2. Refresh your browser at http://localhost:3000
3. Images should load automatically!
